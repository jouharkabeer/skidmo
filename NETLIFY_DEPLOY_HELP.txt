================================================================================
  SKIDMO — Netlify Deployment Guide
================================================================================

This site is a Vite + React SPA with Netlify Functions for the contact form.
Follow these steps to deploy to production on Netlify.

--------------------------------------------------------------------------------
1. PREREQUISITES
--------------------------------------------------------------------------------

  - GitHub / GitLab / Bitbucket repo with this project pushed
  - Netlify account (https://app.netlify.com)
  - Domain: skidmo.sa (or your production domain)
  - SMTP credentials for contact form emails
  - Sanity CMS project (optional — site works with data.json fallback)

--------------------------------------------------------------------------------
2. CREATE A NEW NETLIFY SITE
--------------------------------------------------------------------------------

  Option A — Connect Git (recommended)
    1. Netlify Dashboard → Add new site → Import an existing project
    2. Connect your Git provider and select the SKIDMO repository
    3. Build settings are read from netlify.toml automatically:
         Build command:  npm run build
         Publish directory: dist
         Functions directory: netlify/functions

  Option B — Netlify CLI
    npm install -g netlify-cli
    netlify login
    netlify init
    netlify deploy --prod

--------------------------------------------------------------------------------
3. ENVIRONMENT VARIABLES (Site settings → Environment variables)
--------------------------------------------------------------------------------

  Required for production:

  VITE_SITE_URL=https://skidmo.sa
  VITE_ADMIN_PASSWORD=your-secure-admin-password

  Sanity CMS (if using live CMS instead of data.json only):
  VITE_SANITY_PROJECT_ID=5o4lc5ha
  VITE_SANITY_DATASET=production
  VITE_SANITY_API_VERSION=2024-01-01

  Google Maps embed (footer map):
  VITE_GOOGLE_MAPS_API_KEY=your-google-maps-key

  Elfsight reviews widget (optional):
  VITE_ELFSIGHT_APP_ID=your-elfsight-id

  SMTP — contact form (server-side, NOT prefixed with VITE_):
  SMTP_HOST=smtp.your-provider.com
  SMTP_PORT=587
  SMTP_SECURE=false
  SMTP_USER=your-smtp-username
  SMTP_PASS=your-smtp-password
  SMTP_FROM=hello@skidmo.sa
  SMTP_TO=hello@skidmo.sa

  Notes:
  - Variables starting with VITE_ are baked into the client bundle at build time.
  - After changing VITE_* vars, trigger a new deploy (Clear cache & deploy).
  - SMTP vars are only used by the Netlify Function at runtime.

--------------------------------------------------------------------------------
4. SANITY CORS (if using CMS)
--------------------------------------------------------------------------------

  In Sanity Manage (https://www.sanity.io/manage):
    1. Open project 5o4lc5ha
    2. API → CORS origins → Add origin
    3. Add: https://skidmo.sa
    4. Add: https://your-site-name.netlify.app (for preview deploys)
    5. Allow credentials: Yes

  The site proxies Sanity through /sanity-api/* (see netlify.toml redirects).

--------------------------------------------------------------------------------
5. CUSTOM DOMAIN
--------------------------------------------------------------------------------

  1. Netlify → Site configuration → Domain management → Add domain
  2. Add skidmo.sa (and www.skidmo.sa if needed)
  3. Update DNS at your registrar:
       A record  → 75.2.60.5
       CNAME www → your-site-name.netlify.app
     (Or use Netlify DNS — follow the in-dashboard instructions.)
  4. Enable HTTPS (Netlify provisions Let's Encrypt automatically)
  5. Set VITE_SITE_URL=https://skidmo.sa and redeploy for correct SEO/OG URLs

--------------------------------------------------------------------------------
6. CONTACT FORM
--------------------------------------------------------------------------------

  The form posts to /api/contact, redirected to the Netlify Function:
    netlify/functions/contact.ts

  Test after deploy:
    1. Open https://skidmo.sa/contact
    2. Submit a test enquiry
    3. Check Netlify → Functions → contact → Logs for errors
    4. Verify email arrives at SMTP_TO address

--------------------------------------------------------------------------------
7. ADMIN PANEL
--------------------------------------------------------------------------------

  URL: https://skidmo.sa/admin
  Password: value of VITE_ADMIN_PASSWORD

  Manages: Gallery, Offers, Testimonials, Homepage Stats (via Sanity).

--------------------------------------------------------------------------------
8. BUILD & VERIFY LOCALLY BEFORE DEPLOY
--------------------------------------------------------------------------------

  npm install
  npm run build
  npm run preview

  Check dist/index.html contains correct og:image and meta tags.
  The seoPrerender plugin injects per-route SEO into dist/*/index.html.

--------------------------------------------------------------------------------
9. NETLIFY.TOML SUMMARY
--------------------------------------------------------------------------------

  [build]
    command = "npm run build"
    publish = "dist"

  Redirects:
    /api/contact      → Netlify Function (contact form)
    /sanity-api/*     → Sanity API proxy
    /*                → /index.html (SPA fallback for React Router)

--------------------------------------------------------------------------------
10. TROUBLESHOOTING
--------------------------------------------------------------------------------

  Blank page after deploy:
    - Check build logs for TypeScript or Vite errors
    - Confirm publish directory is "dist"

  Contact form 500 error:
    - Verify all SMTP_* environment variables are set
    - Check Function logs in Netlify dashboard

  Wrong canonical / OG URLs:
    - Set VITE_SITE_URL to production domain and redeploy

  Sanity content not loading:
    - Add production domain to Sanity CORS origins
    - Verify VITE_SANITY_* variables

  Images or fonts broken:
    - Ensure assets are in public/ or imported correctly
    - Clear Netlify cache: Deploys → Trigger deploy → Clear cache and deploy
