================================================================================
  SKIDMO — SMTP Setup Guide (Gmail)
================================================================================

The contact form at https://skidmosa.com/contact sends enquiries via email
using a Netlify Function (netlify/functions/contact.ts).

Business email: skidmoksa@gmail.com

Related files:
  - lib/sendContactEmail.ts   (email sending logic)
  - netlify/functions/contact.ts
  - .env                      (local dev — do NOT commit)
  - .env.example              (template)
  - NETLIFY_DEPLOY_HELP.txt   (Netlify env vars overview)

--------------------------------------------------------------------------------
1. HOW IT WORKS
--------------------------------------------------------------------------------

  1. Visitor submits the contact form on /contact
  2. Browser POSTs JSON to /api/contact
  3. Netlify redirects to the contact function
  4. Function reads SMTP_* env vars and sends email via Gmail SMTP
  5. Email arrives at SMTP_TO (skidmoksa@gmail.com)
  6. Reply-To is set to the visitor's email so you can reply directly

--------------------------------------------------------------------------------
2. GMAIL APP PASSWORD (REQUIRED)
--------------------------------------------------------------------------------

  Gmail does NOT allow your normal account password for SMTP in apps.
  You must create an App Password.

  Prerequisites:
    - Google account: skidmoksa@gmail.com
    - 2-Step Verification enabled on the account

  Steps:
    1. Sign in to https://myaccount.google.com
    2. Security → 2-Step Verification → turn ON (if not already)
    3. Security → App passwords
       (or visit https://myaccount.google.com/apppasswords)
    4. App name: "SKIDMO Website" (or "Netlify Contact Form")
    5. Click Create
    6. Google shows a 16-character password (e.g. abcd efgh ijkl mnop)
    7. Copy it — you will NOT see it again
    8. Use this as SMTP_PASS (spaces optional — both work)

  IMPORTANT:
    - Never commit SMTP_PASS to Git
    - Never put SMTP_PASS in a VITE_ variable (it would be exposed to browsers)
    - Store only in .env locally and Netlify Environment Variables in production

--------------------------------------------------------------------------------
3. ENVIRONMENT VARIABLES
--------------------------------------------------------------------------------

  Add these to .env (local) and Netlify → Site configuration → Environment variables:

  SMTP_HOST=smtp.gmail.com
  SMTP_PORT=587
  SMTP_SECURE=false
  SMTP_USER=skidmoksa@gmail.com
  SMTP_PASS=xxxx xxxx xxxx xxxx
  SMTP_FROM=skidmoksa@gmail.com
  SMTP_TO=skidmoksa@gmail.com

  Variable reference:
  ┌─────────────┬──────────────────────────────────────────────────────────┐
  │ SMTP_HOST   │ Gmail SMTP server: smtp.gmail.com                        │
  │ SMTP_PORT   │ 587 (STARTTLS) — recommended                             │
  │ SMTP_SECURE │ false for port 587; use true only if using port 465      │
  │ SMTP_USER   │ Full Gmail address: skidmoksa@gmail.com                  │
  │ SMTP_PASS   │ 16-character Google App Password (NOT your login pass)   │
  │ SMTP_FROM   │ Sender address shown in inbox (same Gmail account)       │
  │ SMTP_TO     │ Where form submissions are delivered                   │
  └─────────────┴──────────────────────────────────────────────────────────┘

  Optional — send to a different inbox:
    SMTP_TO=another@example.com
  (SMTP_USER/SMTP_PASS must still be the Gmail account that authenticates.)

--------------------------------------------------------------------------------
4. LOCAL DEVELOPMENT TEST
--------------------------------------------------------------------------------

  1. Copy .env.example to .env (if needed)
  2. Set SMTP_PASS to your real App Password in .env
  3. Run: npm run dev
  4. Open http://localhost:5173/contact
  5. Submit a test enquiry
  6. Check skidmoksa@gmail.com inbox (and Spam folder first time)

  Dev server proxies /api/contact to the same sendContactEmail logic via
  vite.config.ts — no separate Netlify CLI needed for local testing.

--------------------------------------------------------------------------------
5. NETLIFY PRODUCTION SETUP
--------------------------------------------------------------------------------

  1. Netlify Dashboard → your SKIDMO site
  2. Site configuration → Environment variables
  3. Add each SMTP_* variable (see section 3)
  4. Scope: Production (and Deploy Previews if you want form testing on previews)
  5. Deploy → Trigger deploy → Clear cache and deploy site
  6. Test live form at https://skidmosa.com/contact

  Verify in Netlify:
    Functions → contact → Logs
    Submit a test form and check for errors like "Invalid login" or "EAUTH"

--------------------------------------------------------------------------------
7. TROUBLESHOOTING
--------------------------------------------------------------------------------

  Error: "SMTP is not configured"
    → SMTP_HOST, SMTP_USER, or SMTP_PASS missing in Netlify env vars

  Error: "Invalid login" / EAUTH / 535
    → Wrong App Password, or using normal Gmail password instead
    → Regenerate App Password and update SMTP_PASS
    → Confirm SMTP_USER is full email: skidmoksa@gmail.com

  Error: "Connection timeout"
    → Check SMTP_HOST=smtp.gmail.com and SMTP_PORT=587
    → Rare on Netlify; retry deploy

  Email sent but not received
    → Check Spam / Promotions in Gmail
    → Confirm SMTP_TO=skidmoksa@gmail.com
    → Check Netlify function logs for success

  Form works locally but not on Netlify
    → SMTP vars not set in Netlify (only in local .env)
    → Redeploy after adding variables

  "Less secure app access"
    → Deprecated by Google — use App Passwords only (section 2)

--------------------------------------------------------------------------------
9. ALTERNATIVE PORT (465 SSL)
--------------------------------------------------------------------------------

  If port 587 is blocked, try:

  SMTP_HOST=smtp.gmail.com
  SMTP_PORT=465
  SMTP_SECURE=true
  SMTP_USER=skidmoksa@gmail.com
  SMTP_PASS=your_app_password

  Default setup (587 + SMTP_SECURE=false) works for most Netlify deployments.
