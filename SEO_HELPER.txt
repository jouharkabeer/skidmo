STEP 0 — BEFORE YOU REGISTER ANYTHING
--------------------------------------------------------------------------------

  1. Deploy to production with custom domain skidmosa.com
  2. Set Netlify env var:
       VITE_SITE_URL=https://skidmosa.com
  3. Trigger a fresh deploy (Clear cache & deploy)
  4. Confirm these URLs work in a browser:
       https://skidmosa.com/
       https://skidmosa.com/robots.txt
       https://skidmosa.com/sitemap.xml
       https://skidmosa.com/og-image.jpg
  5. View page source on homepage — confirm canonical is https://skidmosa.com/

  If VITE_SITE_URL still points to *.netlify.app, Google will index the wrong
  domain and social previews will use incorrect links.

1. GOOGLE SEARCH CONSOLE
--------------------------------------------------------------------------------

  URL: https://search.google.com/search-console

  A) Add property
     1. Click "Add property"
     2. Choose "URL prefix" → enter: https://skidmosa.com
        (Domain property also works but needs DNS TXT verification)

  B) Verify ownership — pick ONE method:

     Method 1 — HTML meta tag (easiest for this project)
       1. Google gives you a tag like:
            <meta name="google-site-verification" content="YOUR_CODE" />
       2. Add it inside <head> in index.html (before </head>)
       3. Deploy to Netlify
       4. Click Verify in Search Console

     Method 2 — DNS TXT record (recommended long-term)
       1. Google gives a TXT record (google-site-verification=...)
       2. Netlify → Domain management → DNS → Add record:
            Type: TXT
            Name: @ (or leave blank for root)
            Value: (paste Google's verification string)
       3. Wait 5–60 minutes, then Verify

  C) Submit sitemap
     1. Search Console → Sitemaps (left menu)
     2. Enter: sitemap.xml
     3. Click Submit
     4. Status should show "Success" within a few days

  D) Request indexing for key pages
     1. URL Inspection (top search bar)
     2. Paste each URL and click "Request indexing":
          https://skidmosa.com/
          https://skidmosa.com/services
          https://skidmosa.com/contact
          https://skidmosa.com/about

  E) Monitor (weekly)
     - Performance → queries (see what people search)
     - Pages → indexing status
     - Core Web Vitals
     - Manual actions (should be none)

6. OPTIONAL — GOOGLE ANALYTICS 4
--------------------------------------------------------------------------------

  Not included by default. To add traffic tracking:

  1. Create GA4 property at https://analytics.google.com
  2. Get Measurement ID (G-XXXXXXXXXX)
  3. Add to index.html before </head>:

       <script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
       <script>
         window.dataLayer = window.dataLayer || [];
         function gtag(){dataLayer.push(arguments);}
         gtag('js', new Date());
         gtag('config', 'G-XXXXXXXXXX');
       </script>

  4. Link GA4 to Search Console:
       Search Console → Settings → Associations → Google Analytics

7. UPDATING SEO IN THE CODEBASE
--------------------------------------------------------------------------------

  File                          What to edit
  ─────────────────────────────────────────────────────────────────────────
  src/constants/seo.ts          Page titles, descriptions, keywords
  vite.config.ts                Prerender meta (PRERENDER_PAGES array)
  public/sitemap.xml            Add new public routes + lastmod dates
  public/robots.txt             Crawl rules (keep /admin disallowed)
  public/og-image.jpg           Social preview image
  src/data/data.json            Site description, parent company links
  index.html                    google-site-verification meta tag

  After editing seo.ts or vite.config.ts → npm run build → deploy.

  When adding a new public page:
    1. Add route in React Router
    2. Add PAGE_SEO entry in src/constants/seo.ts
    3. Add prerender entry in vite.config.ts (PRERENDER_PAGES)
    4. Add <url> block in public/sitemap.xml
    5. Resubmit sitemap in Search Console
